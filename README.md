# 💼 Portafolio_cv

Portafólio pessoal desenvolvido com HTML, CSS e JavaScript, com foco em apresentar minha trajetória, habilidades técnicas e projetos de forma clara e profissional.

🔗 Acesse o projeto:  
https://bernardoigm.github.io/Portafolio_cv/

---

## ✨ Funcionalidades

💻 Interface moderna com estilo glassmorphism  
📱 Layout responsivo (desktop e mobile)  
🧭 Navegação suave entre seções  
🌌 Fundo animado com efeito visual  
📷 Foto de perfil com animação  
💼 Seção de projetos com imagens e descrições  
📬 Formulário de contato funcional (mailto)
